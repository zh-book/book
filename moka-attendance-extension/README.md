# Moka 考勤工时助手（Chrome 插件）

监控 Moka 考勤详情接口，自动从上下班打卡时间计算每日工时：

**工时 = 下班打卡 − 上班打卡 − 午休 1 小时**

监控接口：

```
https://core.mokahr.com/api/abs/attendance/myAttendance/v2/m/detail?bus=20
```

## 本地安装（加载本机目录即可）

本插件不依赖服务器，代码与统计数据都在本机。

1. 打开 Chrome，访问 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本机目录：`moka-attendance-extension`（即含 `manifest.json` 的文件夹）
5. **更新代码后务必点「重新加载」，并刷新已打开的考勤页**

也可直接解压 `dist/moka-attendance-extension.zip` 后按上面步骤加载。

## 使用

1. 登录并打开 Moka 考勤相关页面（`*.mokahr.com`）
2. **硬刷新页面**（Ctrl/Cmd+Shift+R），再点开某天考勤详情以触发接口
3. 点击插件图标：顶部「监听状态」应出现「已看到接口」或「已捕获」
4. 列表展示每日工时、合计与日均；角标为合计小时数

### 监听原理（v1.1）

1. **页面钩子**：`MAIN` world 注入，拦截页面 `fetch` / `XHR`
2. **网络兜底**：`webRequest` 发现目标接口后，扩展凭 cookie 再拉一次响应体
   （即使前端页面不在 `mokahr.com`，只要请求打到 `core.mokahr.com` 也能捕获）

## 计算示例

接口样例中：

- 上班：`2026-08-06 08:52`
- 下班：`2026-08-06 19:57`
- 毛时长：11 小时 05 分
- 扣午休 1 小时后：**10 小时 05 分**（约 10.08h）

## 说明

- 数据仅保存在本机 `chrome.storage.local`，不会上传
- 缺下班卡 / 无打卡会单独标记，不计入合计
- 切换日期让页面重新请求详情接口即可补录历史天
